Shadow Vault is a top-down stealth heist game in pure vanilla JavaScript and canvas — no libraries, fully offline. Sneak through three vault floors past guards with real vision cones (yellow calm, orange suspicious, red chasing) and hearing: sprinting throws a noise ring, crouching (C) in shadow pools makes you almost invisible, and clicking throws a coin that lures guards away. Steal every gem, escape through the EXIT, and earn the +400 unseen bonus if no guard ever reaches full alert. Title, HUD, caught and victory screens with restart are all included.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && node serve.ts
```

Then open http://localhost:8080 — WASD/Arrows move, C crouch, Shift sprint, mouse click throws a coin, P pauses, R retries a floor.
